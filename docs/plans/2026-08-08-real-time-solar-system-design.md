# 実時間太陽系ビューア設計書

## 目的

既存の「星雲の庭」を、端末の現在日時に対応した太陽・8惑星・月の位置を眺められるインタラクティブな3D太陽系へ変更する。外部APIに依存せず、ブラウザ内の天文学的な近似計算で位置を求め、PCとスマートフォンの両方で軽快に操作できる作品を目指す。

表示する位置は鑑賞・教育向けの近似値とし、観測・航法用途の精度は対象外とする。

## 画面体験

- 起動時に、太陽を中心として8惑星と月を現在日時の位置へ配置する。
- 黄道面を斜め上から見下ろす3D視点を初期状態とする。
- 背景には深い宇宙と星空を描画し、各惑星の軌道線と名前ラベルを控えめに表示する。
- ドラッグで視点を回転し、ホイールまたはピンチでズームする。
- 惑星をクリックまたはタップすると、カメラを滑らかに対象へ移動する。
- 詳細パネルには名前、現在位置、太陽からの距離、公転周期、現在の黄経を表示する。
- 「全体を見る」操作で太陽系全景へ戻れるようにする。
- 画面左上に現在日時と「実時間」を表示する。
- 既存の星を引き寄せる操作と小銀河生成は、太陽系の観察操作へ置き換える。
- 共有、PNG保存、環境音は継続する。
- スマートフォンでは詳細情報を画面下部のカードとして表示する。

## 位置計算

端末日時をユリウス日へ変換し、J2000.0を基準とした各惑星の平均軌道要素と経年変化から位置を計算する。

1. 日時からユリウス世紀を求める。
2. 長半径、離心率、軌道傾斜角、平均黄経、近日点黄経、昇交点黄経を更新する。
3. 平均近点角からケプラー方程式を反復計算して離心近点角を求める。
4. 軌道面上の座標を黄道座標へ回転し、太陽中心の3D座標へ変換する。
5. 月は地球を親とした簡略軌道で計算し、地球の位置へ加算する。

位置は一定間隔で再計算し、描画フレーム間は滑らかに補間する。`debugDate` による日時固定を残し、同じ配置を再現できるようにする。

## 距離とサイズ

- 公転軌道の距離は対数関数で圧縮し、海王星までを同一画面に収める。
- 惑星の相対的な遠近感は維持するが、天体半径は識別できるよう別倍率で拡大する。
- このデフォルメを画面内の短い注記で明示する。
- 軌道線は計算済みの楕円から生成し、惑星ごとの軌道傾斜を反映する。

## 描画構成

既存のVite、TypeScript、Three.js構成を維持する。レンダリングを次の責務へ分ける。

1. 日時と軌道要素から天体位置を求める天文計算
2. 太陽、惑星、月、軌道、星空を描画する太陽系レンダラー
3. 回転、ズーム、天体選択を扱うカメラ操作
4. 日時、天体ラベル、詳細カード、共有、画像保存を扱うUI
5. 端末性能に応じて品質を調整する既存のパフォーマンス管理

惑星表現は軽量なThree.jsマテリアルとプロシージャルな色表現を使い、外部画像には依存しない。

## データの流れ

1. 起動時に現在日時または`debugDate`を取得する。
2. 日時から全天体の太陽中心座標と表示用情報を計算する。
3. 対数圧縮した座標をレンダラーへ渡し、天体と軌道を配置する。
4. ポインター操作をカメラ制御とレイキャストによる天体選択へ渡す。
5. 選択天体をUIへ通知し、詳細情報とカメラ目標を更新する。
6. 一定間隔で現在日時と位置を更新し、表示座標を補間する。

## 安定動作とフォールバック

- 日時や計算結果が不正な場合は現在日時へ戻して表示を継続する。
- WebGLが利用できない場合は、現在位置を簡略化した2D太陽系を表示する。
- 低性能端末では星の数、惑星表現、軌道線の分割数を段階的に減らす。
- `prefers-reduced-motion`ではカメラ移動と位置補間を短縮する。
- ズーム範囲とカメラ距離を制限し、選択天体や太陽系全体を見失いにくくする。
- タブ非表示中は描画と音を停止する既存挙動を維持する。

## テスト方針

- ユリウス日変換、ケプラー方程式、座標変換を単体テストする。
- 既知の日付で地球、火星、木星などの位置関係が妥当か確認する。
- `debugDate`で同じ天体配置を再現できることを検証する。
- ドラッグ、ホイール、ピンチ、天体選択、全景復帰をPCとスマートフォンで確認する。
- 詳細パネル、共有、PNG保存、画面回転、WebGLフォールバックを確認する。
- 型検査、単体テスト、ビルド、主要E2Eテストを実行する。

## 完成条件

- 開いた瞬間に現在の太陽系であることが分かる。
- 太陽から海王星までを同時に見渡せる。
- 惑星を選び、迷わず寄って観察して全景へ戻れる。
- 現在日時に応じた惑星位置が近似計算で更新される。
- PCとスマートフォンの両方で滑らかに操作できる。
- デフォルメ表示と近似精度が利用者に明示されている。
