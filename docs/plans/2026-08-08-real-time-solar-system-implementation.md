# 実時間太陽系ビューア実装計画

## 1. 天文計算を追加する

- 天体定義、軌道要素、表示用情報の型を作る。
- ユリウス日変換、軌道要素の経年更新、ケプラー方程式、黄道座標変換を実装する。
- 太陽、8惑星、月の現在位置と黄経を返すAPIを作る。
- 計算の再現性と代表日時の妥当性を単体テストする。

## 2. 太陽系レンダラーへ置き換える

- 既存の星雲、星の引き寄せ、光跡、小銀河を太陽、惑星、月、軌道、星空へ置き換える。
- 対数圧縮した軌道距離と拡大した天体半径を適用する。
- レイキャスト可能な天体メッシュとHTMLラベル投影用座標を公開する。
- 端末品質に応じて星数、軌道分割数、DPRを調整する。

## 3. カメラ操作と選択を追加する

- ドラッグ回転、ホイールズーム、タッチ回転、ピンチズームを実装する。
- クリック／タップ時に天体をレイキャストし、選択状態を更新する。
- 選択天体への滑らかなフォーカスと全景復帰を実装する。
- 動きを抑える設定と画面サイズ変更へ対応する。

## 4. UIとアプリ制御を更新する

- 現在日時、実時間表示、天体ラベル、詳細カード、全景復帰を追加する。
- 共有、PNG保存、環境音を新しい作品名と文脈へ更新する。
- `debugDate`、日時更新、描画停止・復帰、テキスト状態出力を太陽系向けに更新する。
- WebGLフォールバックを簡略2D太陽系へ更新する。

## 5. 見た目とレスポンシブ対応を仕上げる

- 深い宇宙、黄道面、軌道線、情報カードを一貫したビジュアルへ整える。
- モバイルでは詳細カードを下部表示にし、セーフエリアと横向きへ対応する。
- キーボードフォーカス、ARIA、読みやすさを確認する。

## 6. 検証する

- 型検査、単体テスト、lint、production buildを実行する。
- 既存E2Eを太陽系仕様へ更新し、主要操作を確認する。
- 問題があれば修正して再実行する。
